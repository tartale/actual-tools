Export to Actual Dashboard

Builds net-worth, crossover, and Monte Carlo widgets from live balances and the accounts in Accounts. Download the file, then bring it into Actual:

  1. Open your budget in Actual and go to Reports.
  2. Create a new dashboard page (e.g. name it "FIRE") — or reuse one this app already generated.
  3. On that page, open the "…" menu → Import → pick the file you download below.

Importing replaces every widget already on the target page — always import onto a page you're fine wiping. Re-exporting and re-importing onto that same page is the normal way to refresh it; your hand edits there are preserved (see the README).

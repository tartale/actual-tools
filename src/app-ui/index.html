Getting started

No FIRE dashboard is imported into Actual yet. Four steps to get one going:

  1. Below, fill in Plan (birth date, retirement ages to compare, plan-to-age) and check each account's type in Accounts — allocation, contributions, and everything else follow from that.
  2. Switch to the Analyze tab and click Download dashboard.
  3. In Actual: Reports → new dashboard page (e.g. "FIRE") → "…" menu → Import → pick the file you just downloaded.
  4. Open the crossover widget on that page and pick which accounts/categories it should actually count (it starts out covering everything non-income, which is rarely what you want) — this matters: the Monte Carlo widget's own spending figure is read back from that same selection on every future regenerate, not recalculated separately.

Come back here any time after that — this page will show what's actually live under "Configured in the Actual Dashboard" below, and Analyze → Check flags anything that's drifted out of sync as you keep editing.
